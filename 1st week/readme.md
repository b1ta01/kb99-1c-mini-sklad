
Описание
Учебная конфигурация для изучения платформы 1С:Предприятие 8. Демонстрирует работу со справочниками, документами, регистрами и отчётами. Не предназначена для коммерческого использования.

Оказание Услуг

Как открыть
Требования: 1С:Предприятие 8.3 (не ниже 8.3.20), файловый режим.

Загрузка из .dt:

«1С:Предприятие» → «Добавить информационную базу» → «Создание новой информационной базы» → «Без конфигурации».

Указать имя и путь к пустой папке.

Открыть базу в Конфигураторе.

«Администрирование» → «Загрузить информационную базу…» → выбрать .dt из backup/.

Нажать F7 (обновить конфигурацию БД).

Загрузка из папки config/:

Создать пустую базу (см. выше).

В Конфигураторе: «Конфигурация» → «Открыть конфигурацию» → указать папку config/.

Нажать F7.

Проверка работоспособности
Открывается главное окно с разделом «Продажи».

В «Номенклатуре» есть тестовые записи.

Отчёт «Остатки на складе» формируется без ошибок.

Возможные проблемы
Проблема	Решение
Несовместимая версия платформы	Обновить 1С до 8.3.20+
Конфигурация на поддержке	«Конфигурация» → «Поддержка» → «Настройка поддержки» → снять с поддержки
